## Causal Impact of Higher Education on Income

### Overview
This project estimates whether higher education 
truly CAUSES higher income using Machine Learning 
and Causal Inference techniques.

### Key Techniques
- Random Forest (Predictive ML)
- Propensity Score Matching (PSM)
- Average Treatment Effect (ATE)
- Heterogeneous Treatment Effects by age and gender

### Dataset
UCI Adult Census Income Dataset

### Tools
Python | Scikit-learn | Pandas | Seaborn | Matplotlib

### Key Finding
Higher education has a significant positive 
causal effect on income, with varying impact 
across age groups and gender.
